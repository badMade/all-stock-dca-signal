CLOUD-CLONE DRY-RUN TRIAL. READ-ONLY. THIS TASK NEVER PLACES AN ORDER, never calls any Robinhood tool, never calls `evidence_publish claim` or `evidence_publish publish`, never edits tracked files, never changes the scheduler, and never writes run_state.json or a latest-run pointer. Purpose: prove that a cloud container with this repo attached as its source can pass the Gate 2 checks in docs/cloud_clone_runs.md and run the dry-run pipeline, so the seven live slots no longer depend on the Mac bridge.

Set up once, by a human, before the first run (the task cannot do these itself):
- Attach badMade/all-stock-dca as the task's repository source, so the container starts with a checkout in the working directory.
- Task environment variables: DCA_PINNED_SHA (the full 40-character SHA of the green `main` commit being trialled, lower case), DCA_CRON_TRACKING_ROOT (an absolute path, same value every run), DCA_EVIDENCE_REMOTE (URL of the private evidence repo; credential limited to that one repo, Contents read and write), ROBINHOOD_AGENTIC_ACCOUNT_NUMBER (so the secret scan can run; never print it). Network access must allow github.com.
- Schedule it OFF-HOURS, at least 30 minutes away from every live slot, so it can never overlap a trading run.

Steps (use the container's own shell; do NOT use mcp__remote-devices__device_bash or any bridge tool):
1. Shell check. Run `echo shell-ok; python3 --version; git --version; df -Pk . | awk 'NR>1 {print $4/1024 " MiB free"}'`. FAIL if shell-ok is missing, Python is older than 3.11, or free space is under 1024 MiB.
2. Checkout check. Run `test -f config/trading_window.json && echo repo-ok` from the repo root. FAIL with "repo not mounted in executor shell" if repo-ok is missing. This is the same condition as the live Gate 2 abort, so the trial fails the way a live slot would.
3. Preflight. Compute today's date in America/New_York as YYYY-MM-DD, then run `python3 -m scripts.cloud_preflight --repo-root . --evidence-remote "$DCA_EVIDENCE_REMOTE" --evidence-root "$DCA_CRON_TRACKING_ROOT" --trading-day <that date>`. PASS only on exit 0 and a line starting `PREFLIGHT_OK`. On exit 2, record the `GATE2_ABORT:` reason verbatim; this is the most valuable output of the trial. Never pass `--init`. Never remove or edit anything the preflight reports as modified.
4. Dry-run pipeline. Run `python3 run_dca.py --demo --report --now <today>T15:45 --artifacts-dir "$(mktemp -d)"`. PASS only on exit 0. The CLI refuses anything but a dry-run demo, so this step cannot trade. It reads no account data.
5. Report. End with ONE summary line, no tickers, prices, amounts, account numbers or order IDs:
   "Cloud-clone trial <date>: shell <ok/FAIL>, repo <ok/FAIL>, preflight <ok/FAIL: reason>, dry-run <ok/FAIL>, free space <N> MiB, pinned <first 8 chars of DCA_PINNED_SHA>."
   On any FAIL, also send that same line to #dca-alerts (C0BKS1ZL5UY) prefixed "CLOUD TRIAL FAILED:". On all PASS, post nothing else.

Exit criteria for promoting a live slot to the cloud clone (a human decides, not this task): three consecutive weekday runs with every step ok, and one run with the Mac asleep. Until then the live slots keep their current setup.
