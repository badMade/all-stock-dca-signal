# ISSUES.md — Rocket Fuel Audit & Refactor, cycle 1

Generated by a read-only Clarity Break audit (three parallel Explore agents
covering: repo-documented gaps, the "three entry points" duplication risk
`CLAUDE.md` already names, and test/CI health). Ranked by impact. The user
selected all four themes represented below; 6 of the 13 findings became Rocks
in `PLAN.md` this cycle, scoped down to stay inside the 3-7 Rock limit. The
rest are carried to `DEFERRED.md`.

## impact: high

- Three independent budget-cap tracking mechanisms with no shared code —
  `near_close_dca.StrategyState` (near_close_dca.py:1854),
  `dca_runner.BudgetSnapshot` (dca_runner.py:1163, sums broker order history),
  and `morning_dca.MorningLedger` (morning_dca.py:786, explicitly documented as
  sharing no state with `StrategyState`). Concrete drift already exists: the
  sibling-stream list each seeds from (`cap_seed_roots`) is hand-duplicated
  three times in different orders (`morning_dca.py:493`,
  `market_open_dca.py:186`, `intraday_dca.py:194`). **→ Rock 1** (dedupe the
  root lists only; unifying the three tracking models themselves is out of
  scope — see DEFERRED.md).

- Two independently-written same-day "already bought" reconciliation
  implementations — `StrategyState.reconcile_prior_allocation()`
  (near_close_dca.py:2742) and `morning_dca._compute_top_up()`/`TopUpOutcome`
  (morning_dca.py:3690, :589) — different data structures, different edge-case
  handling, no shared code path. **→ Rock 2** (pin the documented relationship
  with a parity test; do not unify).

- Stale-branch/squash-merge clobbering is a *recurring* failure mode: PR #658
  reverted `main` by ~150k lines on 2026-09-03, then 4 days later
  (2026-09-07, `claude/PR-1348-REVIEW-FOLLOWUP.md`, commit `67f26c9b`) a second
  near-miss briefly deleted the SSRF fix (`BlockedFileHandler`/
  `BlockedFTPHandler`) and 6 tests from a stale branch — caught only by manual
  vigilance. **→ Rock 3** (cross-module protected-surface canary test).

- Recurring "fix test after merge" pattern: commits like `bee493f4`,
  `e37b9fec`, `1c764085`, `c5ffa0f5`, `e0e8e79b` all patch tests/lint *after*
  the PR that broke them already landed on main. **→ not a Rock this cycle**
  (process observation, no single code fix; partially mitigated by Rocks 3-4
  making the specific known-fragile invariants harder to silently break).

- Recurring security near-miss pattern documented in `.jules/sentinel.md`:
  unsanitized external-response logging leaked secrets twice, unescaped
  external data caused XSS three times, and the SSRF fix in
  `strategy_monitor.py`/`drift_detection.py` had to be iterated multiple times
  before centralizing in `dca_net_utils.assert_safe_destination`. No open
  vulnerability found. **→ Rock 4** (structural test pinning the
  build_opener-carries-safety-handlers invariant for in-scope core modules).

## impact: medium

- `config/budgets.json`'s `one_order_per_ticker_per_day: true` still
  contradicts `same_day_top_up_policy` — explicitly flagged unresolved in
  `claude/SECOND-EXECUTOR-FINDING.md`. **→ DEFERRED** (needs a domain decision
  on intended trading semantics, not a Codex-authored fix).

- Built, tested reliability engines (`broker_reconciliation.py`,
  `run_state_machine.py`, `run_ledger.py`, `idempotency.py`,
  `scheduler_lease.py`, `reason_codes.py`) are not wired into the live decision
  path (`docs/reliability_spec.md` §10, "Pending"). Two live executors each use
  their own ad hoc `ref_id` scheme instead of the shared `idempotency.py`.
  **→ DEFERRED** (CLAUDE.md: "Consolidating is a decision, not a cleanup").

- Three root-level modules have zero test coverage and are not in the coverage
  `omit` list: `build_raw_data.py`, `run_market_open_signals.py`, `snap.py`.
  **→ Rock 5**.

## impact: low

- CI fragility: GitHub Actions pinned by mutable tag
  (`actions/checkout@v7`) not SHA; no dedicated secret-scanning step; Pyright
  is configured but explicitly not a CI gate. **→ Rock 6** (SHA-pinning only;
  secret-scanning and Pyright-as-gate deferred).

- Machine-specific hardcoded paths and opaque scheduler task IDs baked into
  code, violating `AGENTS.md`'s own no-hardcoded-path rule
  (`PRODUCTION_READINESS.md`). **→ DEFERRED** (largely lives in external
  prompt text outside this repo).

- A real-looking account number is committed as the test default in
  `conftest.py`/`tests/test_morning_dca.py`. **→ DEFERRED** (already mitigated
  by `test_config_invariants.py`'s regex gate).

- Dead Polygon fetch subsystem (5 of 5,502 tickers fetched, blocked on missing
  credentials since 2026-04-26) flagged for archival/deletion, never done.
  **→ DEFERRED** (needs confirmation nothing still depends on the partial
  functionality before deleting).

- Low-traceability commits landing directly on `main` with non-descriptive
  messages ("ok go", "dodod", "gogogo") and bare merge commits with no PR
  context. **→ DEFERRED** (human process observation, not a code fix).
