# third-party dependencies). Install with:  pip install -r requirements-dev.txt

# Versions are pinned rather than floored so a new upstream release can never
# turn main red without a deliberate commit here: a new ruff minor can add a rule
# to the selected E/F/I/B sets, and a new pytest major can change collection
# behavior. Bump these intentionally (dependabot opens the PR).

# schemas/*.json are a load-bearing contract (run_state, run_classification,
# pointers, cost tracker). Every schema test used to guard its import with
# `except ImportError: return`, so with jsonschema absent from this file the
# whole schema suite silently passed while asserting nothing. It is a hard dev
# dependency now and the tests use pytest.importorskip, which reports a real
# SKIP instead of a false PASS.
