# taste profile

Seeded from the setup brief, not from an interview. Run `profile-interview` to replace it; it merges rather than
overwrites.

How work is judged:

- Tests first. A behavior change without a test derived from expected behavior is not done.
- Clean Code. Small functions, intention-revealing names, no duplication, no dead code.
- Determinism. Same input, same output; seed randomness and fix the clock.
- Minimal. The smallest change that meets the goal beats the clever one.
- Evidence. A claim without a source or a run is a hypothesis.
