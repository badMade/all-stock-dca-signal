# voice profile

Seeded from the setup brief, not from an interview. Run `profile-interview` to replace it; it merges rather than
overwrites.

- Direct. State the point first, no throat-clearing.
- Minimal. A short sentence is precise, not lazy.
- Code first. Show the runnable command or the diff before the explanation.
- No em dashes. No exclamation points.
- Separate facts, assumptions and recommendations; say where confidence is low.
