# Reflections: 2026-10-18

## Session: Capex scanner fixes, auto-refresh automation, venv recovery (10:06)

### What worked
- Reading the review's four findings against the code exposed that the weekly runner duplicated the live logic, so extracting one shared function fixed both entry points and one regression test on the runner pinned it.

### What didn't
- I made a `.venv` symlink in a scratch worktree to borrow the user's venv; it was git-visible, got swept into a blanket commit onto main, failed a CI test, and a later `git checkout main` in the user's checkout overwrote their real `.venv` directory. I also first wrote a new file into the user's checkout while it sat on their feature branch.

### Lesson (one sentence, actionable)
Never place symlinks or scratch files inside a repo tree (checkout or worktree) that other sessions commit from; run tools by absolute interpreter path instead, and check `git ls-files` for stray entries before switching branches in a shared checkout.
